# Marca Wasakaka — logo oficial casa-chef

Logo oficial desde el 2026-11-17 («por el momento»): casa naranja con gorro
de chef crema dentro y onda naranja; el nombre «Wasakaka» va mitad crema y
mitad naranja, con el eslogan «Comida casera de tu barrio».

## Archivos

- `wasakaka-logo-fondo-oscuro.png` — logo completo sobre marrón chocolate.
  Es la versión principal: el crema solo se lee sobre fondos oscuros.
- `wasakaka-logo-transparente.png` — logo completo con fondo transparente,
  para superficies oscuras.
- `wasakaka-logo-claro-1024.png` — logo completo para fondos claros: la
  mitad crema pasa a marrón chocolate para que se lea.
- `wasakaka-simbolo-fondo-oscuro.png` — solo la casa y el gorro, sobre
  marrón.
- `wasakaka-simbolo-512.png` — símbolo transparente (fondos oscuros).
- `wasakaka-simbolo-claro-512.png` — símbolo para fondos claros; es el que
  usa el encabezado de la app (`public/logo.png`).
- `wasakaka-icono-app-1024.png` — ícono de app: el símbolo sobre marrón.

## Regla de uso

- Fondo oscuro → versiones en crema y naranja.
- Fondo claro → versiones «claro» (el crema se vuelve marrón).
- El diseño anterior (casa terracota con bol verde de guasacaca) quedó
  guardado como alternativa fuera de este paquete.
